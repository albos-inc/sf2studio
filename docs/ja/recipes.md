## 1. 2 つの SF2 を聞き比べる

1. **比較** モードにします。
2. レーン **A** の **シンセ** を **sf2synth** にし、**音源** を開いて **ファイルを選ぶ（SF2 / DLS / SFZ）…** から
   1 つ目の SF2 を選びます。**音色** で楽器を選びます。
3. レーン **B** も同じように 2 つ目の SF2 にします（シンセも **sf2synth** にすれば、違いは音源だけになります）。
   3 つ以上なら **レーンを追加**。
4. **再生する内容** でテストパターン（まずは **和音（弱 → 強）** がおすすめ）か **MIDI ファイルを開く…** を選びます。
5. **音量を揃える** はオンのままにします（音量の差で判断してしまわないように）。
6. **Space** で再生し、再生中に **1** と **2**（または **出力** のチェック）でレーンをオン・オフするか、
   **Tab** で 1 本ずつ順に聞きます。
7. [スペクトログラム](reading-the-display.md) やレーンの数値（音量・明るさ）も見比べます。

![レーン](../images/ja/compare-lanes.png)

<a id="r2"></a>

## 2. 同じ SF2 で sf2synth と Mac 標準の違いを聞く

macOS で初めて起動したときは、この状態になっています。

1. **比較** モード。レーン **A**: シンセ **sf2synth**、音源は調べたい SF2（または内蔵 GS 音源）。
2. レーン **B**: シンセ **Mac 標準**、音源 **A と同じ**（A のファイルと音色に従います）。
3. **ベロシティの段階** を選んで **Space**、**Tab** で切り替えます。
4. **表示** の **計測グラフ** をオンにして、強さへの反応が同じか見ます（[手順 5](#r5)）。
5. sf2synth を Mac 標準に近づけたい（またはその逆）なら、**調整再生** モードで調整します（[手順 8](#r8)）。

<a id="r3"></a>

## 3. 録音と SF2 を聞き比べる

WAV のレーンは「再生する内容」に関係なくファイルの先頭から鳴るので、同じ曲を演奏した録音が必要です。

1. 比べたい楽器（本物のピアノ、ハードウェア音源、ほかのアプリなど）で MIDI ファイルを演奏して録音し、WAV で保存します。
2. **比較** → **MIDI ファイルを開く…** → 同じ MIDI ファイル。
3. レーン A: **sf2synth** と SF2。**レーンを追加** → **シンセ** を **WAV（録音）** → **WAV を選ぶ…** → 録音。
4. タイムラインで音の位置が揃っているか確かめます。スペクトログラムの音が、同じピアノロールの音符の下で始まっていれば OK。
   録音が遅れて始まるなら、音声編集ソフトで先頭の無音を削り、最初の音から始まるようにします
   （テストパターンは 0.2 秒から始まります）。
5. 手順 1 と同じように再生して切り替えます。

<a id="r4"></a>

## 4. 本当に違いが聞き分けられるか確かめる

1. 比べる 2 本のレーンを用意します（手順 1〜3）。**音量を揃える** はオンに。音量の差はすぐ聞き取れてしまい、ほかの違いを隠すからです。
2. タイムラインの短い部分を Shift+ドラッグしてループにします。
3. **ブラインドテスト** をオンにし、ウィンドウの **比べるレーン** で 2 本を選びます。
4. **🔊 A**、**🔊 B**、**🔊 X** を好きなだけ聞き、**X は A** か **B** を答えます。
5. 8 回以上くり返します。正解数と、当てずっぽうでその成績になる確率が表示され、5% 未満なら **聞き分けられています** と出ます。
6. ウィンドウを閉じる（またはブラインドテストをオフにする）と、レーンの表示が元に戻ります。

## 5. 強さに応じて音量と明るさがどう変わるか調べる

1. **比較** モード、比べるレーンを用意し、**再生する内容 → ベロシティの段階**。
2. **表示 → 計測グラフ** をオン（**鍵ごとの最大を基準にする** もオン）。
3. グラフを読みます。
   - **ベロシティ → 音量**: 傾きが急なほど強弱の差が大きい。
   - **ベロシティ → 明るさ**: 右上がりなら強く弾くほど明るい。
4. sf2synth の反応を変えるには手順 8、音源そのものの反応を変えるには [作成モードのタッチ](create.md#touch) を使います。

![グラフ](../images/ja/measurements.png)

<a id="r6"></a>

## 6. 音域ごとの響きの長さを比べる

1. **比較** → **再生する内容 → 長い音（減衰）**。
2. **計測グラフ** をオン。**鍵盤ごとの減衰** に、C1 から C7 までの 40 dB 下がるまでの秒数がレーンごとに出ます。
3. タイムラインでは、各レーンの音量推移の傾きと、スペクトログラムの縞がどこまで残るかを見比べます。

<a id="r7"></a>

## 7. 1 音の倍音を観察する

1. **調整再生** モード。SF2 を選んだ **sf2synth** のレーンを選びます（**再生中: A**）。
2. レーンを高く表示したければ、**表示** の **拡大波形** と **ピアノロール** をオフにします。
3. 鍵盤を押し、鳴らしたい長さだけ押してから離します。
4. 全レーンがその音を表示します。緑の線が基音と倍音 ×2〜×8 の位置です。ピンチや Ctrl+スクロールで拡大できます。
5. **Space** で聞き、**1**/**2** や **Tab** でほかのレーンを聞きます。

![1 音](../images/ja/timeline-note.png)

<a id="r8"></a>

## 8. sf2synth のタッチを調整して保存する

1. **調整再生** モードで、調整したい sf2synth のレーンを **再生中** にします。
2. 同じ強さで繰り返したいなら **強さを固定** をオン。
3. 弱い音と強い音を弾き（鍵盤の上の方で弱く、下の方で強く）、右で調整します。
   - 弱音が小さすぎる → **幅 (cB)** を小さく、または **凹型** を選ぶ
   - 弱音が明るすぎる → **弱音をこもらせる** をよりマイナスに
   - レーン全体が大きすぎる・小さすぎる → **全体の音量**
4. 変えるたびにレーンを書き出し直します。同じ鍵盤をもう一度弾いて確かめます。
5. **保存…** で TOML ファイルに書き出します。**読み込む…** で、このレーンやほかの sf2synth レーンに読み戻せます。
   **初期値に戻す** で既定値に戻ります。

同じ TOML は、自作のプログラムで sf2synth を設定するのにも使えます。[リファレンス](reference.md#toml) を参照してください。

<a id="r9"></a>

## 9. SF2 のピアノを明るく、余韻を長くする

1. **作成** → **元にする音: 既存の SF2 / SFZ** → **SF2 / DLS / SFZ を選ぶ…** → ピアノの SF2 → **プリセット** を選ぶ。
2. **名前** を入力します。
3. **明るさ（高域）** を数 dB 上げてくっきりさせます。低音がもたつくなら **温かみ（低域）** を少し下げます。
4. **押したままの減衰** を、押し続けた音を響かせたい秒数に（例 15 秒）、**離したあとの余韻** を離してから響く長さに（例 0.8 秒）。
5. 変えるたびに鍵盤で弾いて確かめます（少し待つとできあがります）。
6. **SF2 を保存…**。

<a id="r10"></a>

## 10. 録音から SF2 を作る

1. 楽器を 1 音ずつ別のファイルに録音します。数半音おきで十分です（各録音が隣との中間までを受け持ちます）。
   楽器として響かせたい長さまで録音します。
2. ファイル名に音名を入れます: `C2.wav`、`F#2.wav`、`C3.wav` …（または `piano_048.wav` のような MIDI 番号）。
3. **作成** → **元にする音: 録音** → **WAV を追加…** → まとめて選びます。各ファイルの横に正しい鍵盤が出ているか確かめます。
4. 整えて（タッチの **強さのレイヤー数** を 2〜3 にすると、弱音から強音への音色の変化が自然になります）、弾いて確かめます。
5. **SF2 を保存…**。

![録音から作る](../images/ja/diagram-recordings.svg)

<a id="r11"></a>

## 11. ファイルなしでピアノの SF2 を作る

1. **作成** → **元にする音: 合成**。
2. 鍵盤を弾きながら **明るさ**、**弦の硬さ**、**減衰（中央の C）**、**弦のずれ**、**ハンマーの打音** を調整します。
3. 必要なら中央の設定でさらに整え、**SF2 を保存…**。

<a id="r12"></a>

## 12. 作った音源を元の音源と比べる

1. **作成** モードで音源を作ります（手順 9〜11）。
2. **比較に追加** をクリック。新しいレーン（例 C）に入ります。
3. **比較** モードに切り替えます。元の音源はレーン A のまま。手順 1 のように聞き比べるか、ブラインドテスト（手順 4）をします。
4. 直したくなったら **作成** に戻って変更します。比較モードのレーンは変更のたびに自動で更新されます。

![比較モードの新しい音源](../images/ja/compare-created.png)

<a id="r13"></a>

## 13. 同じ部分を繰り返し聞く

- タイムラインを **Shift+ドラッグ**: その範囲がループになります（薄い帯）。**L** か、再生バーの範囲の横の **×** で解除。
- または **ピアノロールの音符をクリック**: その音をループして再生します。
- **←** / **→** で 5 秒ずつ移動、**Home** で先頭へ。

<a id="r14"></a>

## 14. 自分の曲で音源を比べる

1. **比較**（または調整再生）→ **MIDI ファイルを開く…** → 手持ちの `.mid` ファイル。
2. 各レーンの音色は、ドラム以外の全チャンネルの楽器を置き換えます（ファイル内のプログラムチェンジは効きます）。
   公平に比べるには、1 つの楽器のための曲（ピアノ曲など）を使います。
3. 手順 1 と同じように再生して切り替えます。

<a id="r15"></a>

## 15. MIDI キーボードで弾く

1. キーボードをつなぎ、**調整再生**（または作成）モードにします。
2. 鍵盤の上の **MIDI キーボード** のメニューを開き（開いたときに見つかった入力が並びます）、使うキーボードを選びます。
3. 弾きます。聞いているレーン（調整再生）または作っている音源（作成）で、余計な遅れなく鳴ります。
   調整再生では、離すたびにその音を全レーンで書き出します。

<a id="r16"></a>

## 16. まったく同じ音を何度も鳴らす

1. **調整再生** → **強さを固定** をオンにしてスライダーを設定（例 100）。
2. **長さを固定** をオンにして秒数を設定（例 2 秒）。
3. 鍵盤をクリックすると、どうクリックしてもその強さ・その長さで鳴ります。設定を変えてもう一度クリックすれば、違いだけを聞けます。

<a id="r17"></a>

## 17. 音源を小さな SFZ で保存し、同じ音か確かめる

1. **作成** モードで音源を作ります（既存の音源を作り直しても構いません）。
2. **SFZ を保存…** で名前を付けて保存します。SFZ ファイルと、可逆圧縮 FLAC のサンプルを入れたフォルダが隣にできます。
3. **比較に追加** — 作った音源を鳴らすレーンができます。
4. **比較** → **レーンを追加** → **音源** → **ファイルを選ぶ（SF2 / DLS / SFZ）…** → 保存した SFZ。
5. **表示: ヌルテスト（差分）** をオンにして、その 2 つのレーンを選ぶと「完全に一致」。SFZ は SF2 とまったく同じ音で鳴ります。
