## キー操作

文字の入力欄を編集していないときに使えます。

| キー | 調整再生 | 比較 |
|---|---|---|
| Space | 再生 / 一時停止 | 再生 / 一時停止 |
| 1〜9 | レーン A〜I を聞く | レーン A〜I の出力をオン・オフ |
| Shift+1〜9 | — | そのレーンだけを鳴らす |
| Tab | 次のレーンを聞く | 次のレーンだけを鳴らす |
| ← / → | 5 秒戻る / 進む | 5 秒戻る / 進む |
| Home | 先頭へ | 先頭へ |
| L | ループを解除 | ループを解除 |

ブラインドテスト中は、レーンがわかってしまわないよう Space 以外は効きません。

## マウス・トラックパッドの操作

| 場所 | 操作 | 結果 |
|---|---|---|
| タイムライン | クリック / ドラッグ | 再生位置を移動 |
| タイムライン | Shift+ドラッグ | 範囲をループ |
| タイムライン | ピンチ、Ctrl+スクロール | ポインタ位置を中心に拡大縮小 |
| タイムライン | スクロール | 左右に移動 |
| タイムライン | ダブルクリック | 全体表示、再生位置への追従を再開 |
| レーンのヘッダー | クリック | そのレーンを選ぶ（▶） |
| ピアノロール | 音符をクリック | その音をループして再生 |
| 拡大波形 | スクロール | ±1〜500 ms で拡大縮小 |
| 出力のチェック | Shift+クリック | そのレーンだけを鳴らす |
| 鍵盤 | 鍵盤の上の方 / 下の方を押す | 弱く / 強く |
| 鍵盤 | 鍵盤の上をドラッグ | グリッサンド |
| パネルの境目 | ドラッグ | パネルや鍵盤の大きさを変える |

## コマンドライン

```sh
sf2studio --sf2 piano.sf2 --mac piano.sf2 --mac-builtin --midi song.mid --mode compare
```

| オプション | 働き |
|---|---|
| `--sf2 <ファイル>` | そのファイルを鳴らす sf2synth のレーンを追加 |
| `--mac <ファイル>` | そのファイルを鳴らす Mac 標準のレーンを追加 |
| `--mac-builtin` | macOS 内蔵 GS 音源を鳴らす Mac 標準のレーンを追加 |
| `--wav <ファイル>` | WAV のレーンを追加 |
| `--midi <ファイル>` | その MIDI ファイルを再生する内容にする |
| `--mode create\|tune\|compare` | そのモードで開く |
| `--create <sf2>` | そのファイルを元にする音として作成モードで開く |
| `--theme light\|dark\|system` | テーマを設定 |
| `--show help\|about` | 起動時にそのウィンドウを開く |

レーンのオプションは、書いた順にレーンを追加し、保存されていたレーンを置き換えます。

## ファイル

| 種類 | 使い道 |
|---|---|
| SF2（`.sf2`） | レーンの音源。作成モードの元にする音と、できあがる音源 |
| DLS（`.dls`） | レーンの音源（sf2synth は DLS も読めます）。作成モードの元にする音。macOS と Windows には GS 音源が内蔵されています |
| WAV（`.wav`） | 録音のレーン、作成モードの録音。16 / 24 / 32 ビットまたは浮動小数点、モノラルでもステレオでも、サンプルレートは問いません（変換します） |
| MIDI（`.mid`、`.midi`、`.kar`、`.rmi`） | レーンが鳴らす内容 |
| TOML（`.toml`） | 調整再生モードで保存した sf2synth の設定 |

<a id="toml"></a>

### 設定ファイル（TOML）

調整再生モードの **保存…** で、たとえば次のようなファイルができます。

```toml
master_gain_db = -6.0206
velocity_range_cb = 960.0
velocity_curve = "Concave"
velocity_filter_cents = -2400.0
initial_attenuation_scale = 0.4
cubic_interpolation = true
release_same_key = true
reverb_send = 0
reverb_room = 0.6
reverb_damping = 0.4
reverb_width = 1.0
reverb_level = 0.8
chorus_send = 0
chorus_level = 0.6
max_voices = 256
```

| キー | スライダー | 意味 |
|---|---|---|
| `master_gain_db` | 全体の音量 | 出力の音量（dB） |
| `velocity_range_cb` | 幅 (cB) | ベロシティ → 減衰の量（センチベル。10 cB = 1 dB） |
| `velocity_curve` | カーブ | `Concave`（凹型）、`Linear`（直線）、`Convex`（凸型） |
| `velocity_filter_cents` | 弱音をこもらせる | ベロシティ 0 でのフィルター周波数の下げ幅（セント。0 = なし） |
| `initial_attenuation_scale` | 減衰の係数 | ファイルの減衰の効かせ方（0.4 = E-mu 流、1.0 = 仕様どおり） |
| `cubic_interpolation` | キュービック補間 | `false` で直線補間 |
| `release_same_key` | 同じ鍵盤の再打鍵で前の音を離す | |
| `reverb_send`、`chorus_send` | 送り（CC91 / CC93） | 再生前に全チャンネルに送る値（0〜127） |
| `reverb_room`、`reverb_damping`、`reverb_level`、`chorus_level` | 各スライダー | 0〜1 |
| `reverb_width` | — | リバーブのステレオの広がり（0〜1） |
| `max_voices` | — | 同時に鳴らせる音の数（16〜4096） |

書かれていないキーは既定値になるので、変えたいものだけを書いたファイルでも読み込めます。

## 終了後も覚えている内容

言語、テーマ、モード、再生する内容、すべてのレーン（シンセ・音源・音色・sf2synth の設定）、音量を揃える、表示の切り替え、
鍵盤の設定、作成モードの元にする音と整える設定。覚えないもの: 作った音源（SF2 を保存… で保存）、再生位置・ループ・拡大の状態、
ブラインドテストの成績。

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 上部バーに赤いスピーカーのアイコンとメッセージ | 音声出力を開けませんでした。出力デバイスを確かめ、sf2studio を起動し直してください。表示は使えます。 |
| 「左のレーンで SF2（または WAV）を選ぶと始まります。」 | どのレーンにも鳴らすものがありません。レーン A の音源（または WAV）を選びます。 |
| レーンの数値の代わりに赤い文字 | ファイルを読めない・鳴らせない理由が出ています。別のファイルや音色を選びます。 |
| 調整再生で鍵盤が鳴らず、黄色い文字で sf2synth のレーンを求められる | 聞いているレーンが sf2synth でないか、音源が選ばれていません。音源を選んだ sf2synth のレーンにします。 |
| 調整再生で「いま再生中のレーンは sf2synth ではありません」 | 設定は sf2synth のレーンだけのものです。 |
| 比較でグラフが出ず、テストパターンを選ぶよう表示される | 計測には「ベロシティの段階」「長い音」「半音階」が必要です。 |
| 比較で出力のチェックが消えた | ブラインドテスト中です。ウィンドウを閉じます。 |
| 出力レベルが赤くなる | 音が割れています。全体の音量（調整再生）や音量（作成）を下げるか、音量を揃えるをオンにします。 |
| WAV のレーンの位置がずれる | WAV はファイルの先頭から鳴ります。録音の最初の音が MIDI ファイルの最初の音と同時になるよう、先頭を削ります。 |
| MIDI キーボードが一覧にない | つないでからメニューを開き直します（開くたびに一覧を読み直します）。 |
| 作成で「強さのレイヤー数」が効かない | 1 つのサンプルが全ベロシティを受け持つ場合だけ作ります。元の音源に、すでにベロシティごとのサンプルがあります。 |
| 作成モードで作った音源が再起動で消えた | 作った音源は保存されません。終了前に SF2 を保存… を使います。 |
| Mac 標準が選べない | macOS の機能です。Windows では録音と比べてください。 |

## 用語集

| 用語 | 意味 |
|---|---|
| SF2（SoundFont 2） | サンプルと、それを楽器として鳴らすための決まりを収めたファイル |
| DLS | Downloadable Sounds。似た形式で、OS 内蔵の GS 音源は DLS |
| GS 音源 | macOS と Windows に内蔵されている General MIDI の楽器一式（Roland GS） |
| プリセット · バンク · プログラム | SF2 の中の楽器。`バンク:プログラム` の番号で呼ぶ |
| ベロシティ | 音の強さ（1〜127） |
| セント · cB | 半音の 100 分の 1 · デシベルの 10 分の 1 |
| 倍音（パーシャル） | 音を形作る周波数成分。整数倍のものが倍音 |
| 倍音のずれ（インハーモニシティ） | 倍音が整数倍より高めにずれること。ピアノ弦の硬さによる |
| スペクトル重心 | 音量で重みをつけた平均周波数。明るさの目安 |
| RMS 音量 | 音の平均的なパワー（dB） |
| レーン | シンセ＋音源＋音色（または録音）の 1 組。1 行で表示され、1 つの音として聞ける |
| ABX | ブラインドテスト。正体を隠した X が A と B のどちらと同じかを答える |
